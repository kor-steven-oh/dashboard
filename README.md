# Samsung People Analytics

경영진을 위한 인력 운영 대시보드 샘플입니다. 구성원 개인 명단 대신 **직무·근속·조직구조·전략 프로젝트 배치**를 보여줍니다. 모든 인력, 비용, 조직 및 프로젝트 수치는 가상 데이터입니다.

## 화면 열기

- [기본 화면](index.html): ver.2와 동일한 Liquid Glass 대시보드
- [ver.1](ver.1.html): 삼성 블루를 포인트로 사용한 클래식 경영 대시보드
- [ver.2](ver.2.html): Tahoe 파란 물결 영상과 Liquid Glass 소재를 적용한 대시보드

HTML 파일을 브라우저에서 바로 열 수 있습니다. 모든 버전에서 `assets/` 폴더를 같은 위치에 함께 두세요. 전체 글꼴은 로컬에 포함한 Pretendard 가변 폰트를 사용합니다. 설치나 빌드 과정은 없습니다. 데스크톱 가로 1,180px 이상을 기준으로 제작했습니다.

로컬 서버로 확인하려면:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 화면 상단에서 버전을 전환할 수 있습니다.

## 구성과 동작

- **핵심 지표:** 총 재직 인원, 월간 인건비, 전략 프로젝트 배치율, 정원 대비 부족 인원
- **직무 포트폴리오:** 주 직무 기준 6개 분류의 정원·현원 비교
- **근속 구조:** 4개 근속 구간의 비중과 가중 평균 근속
- **조직구조:** 6개 본부의 정원·현원, 팀 수, 충원 상태
- **프로젝트:** 5개 전략 과제의 주관 조직, 목표 일정, 투입·계획 인원, 추가 배치 필요, 운영 상태
- 조회 월(2026년 7–9월)과 조직 필터가 전체 지표에 함께 적용됩니다.
- 카드, 차트, 표에는 마우스 오버·키보드 포커스 상세 정보가 있습니다. 조직·직무·근속·프로젝트를 누르면 상세 창이 열립니다.
- 프로젝트 검색·상태 필터·정렬과 통합 검색(`⌘ K` / `Ctrl K`), CSV 다운로드를 지원합니다.
- 라이트·다크 테마와 메뉴 접기를 지원합니다.

ver.2에는 유리 질감/불투명 패널 전환, 배경 영상 재생/일시정지, 움직임 감소·투명도 감소·고대비 환경설정 대응을 추가했습니다. 비활성 탭에서는 영상을 자동 정지합니다. 테마와 영상 정지·화면 소재 설정은 브라우저에 저장됩니다.

## 데이터 기준

9월 전체 조직 기준: 현원 **1,284명**, 정원 **1,320명**, 월간 인건비 **96.5억원**(예산 99.0억원), 전략 프로젝트 투입 **815명** / 계획 **897명**입니다.

직무·근속 합계는 현원과 일치합니다. 프로젝트는 주 참여 프로젝트로 1인 1회 집계합니다. 일반 운영 인력 469명은 일상 운영과 기타 과제 수행 인원이며 유휴 인원을 뜻하지 않습니다. 조직 정원 부족과 프로젝트 추가 배치는 별도 지표로 합산하지 않습니다. 화면의 ‘지표 정의’에서 산식을 확인할 수 있습니다.

## 파일 구조

```text
index.html                   기본 진입점, ver.2와 동일
ver.1.html                   클래식 버전 (CSS·JS 내장)
ver.2.html                   Liquid Glass 버전 (CSS·JS 내장)
assets/fonts/                Pretendard 가변 폰트와 OFL 라이선스
assets/tahoe-light-web.mp4    원본의 H.264 호환용 변환본
assets/tahoe-light-poster.jpg 원본 영상의 첫 프레임
sample.png                   사용자 제공 레이아웃 참고 이미지
ASSETS.md                    영상 출처와 변환 정보
scripts/verify.mjs           데이터·CSV·파일 검증
```

배경 영상은 HEVC 지원 브라우저에서 Apple 원본을 직접 재생하며, 미지원·오프라인 또는 원본 로드 실패 시 로컬 MP4로 대체합니다. 영상 자동재생을 제한하는 브라우저에서는 왼쪽 아래 Tahoe 버튼을 누르면 됩니다. 원본은 약 45MB, 로컬 호환본은 약 6.6MB입니다. [영상 출처](ASSETS.md)

`ver.1.html`은 비교 기준으로 보존합니다. 공통 데이터나 집계 로직을 수정할 때는 양쪽 버전에 동일하게 반영하고, `index.html`은 `ver.2.html`과 동일하게 유지하세요.

## 검증

Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node scripts/verify.mjs
```

21개 월·조직 조합의 인원 합계, 월간 인원 수지, 비용·배치 범위, 프로젝트 검색·상태·정렬, 필터 적용 CSV, HTML ID·SVG 참조·에셋 존재 및 버전 간 로직 일치를 확인합니다.

Safari에서 두 버전의 렌더링, 상세 창, 프로젝트 검색, 조직·월 필터, 영상 재생/정지 및 다크 모드를 직접 확인했습니다. CSV 버튼의 파일 생성 요청과 필터가 적용된 CSV 내용도 검증했습니다.
